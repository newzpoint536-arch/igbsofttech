# IGB SOFT-TECH Website

A professional, futuristic, and responsive website for IGB SOFT-TECH, a Nigerian digital marketing agency.

## Features

### 🚀 Core Features
- **5 Complete Pages**: Home, About, Services, Portfolio, Contact
- **Futuristic Design**: Glassmorphism, animated gradients, modern UI
- **Mobile-First Responsive**: Works perfectly on all devices
- **WhatsApp Integration**: Direct lead generation to WhatsApp
- **Interactive Elements**: Hover effects, animations, counters

### 🎨 Design Elements
- **Color Scheme**: Dark Blue (#0D1F3C) & Gold (#FFB800)
- **Typography**: Modern sans-serif fonts
- **Glassmorphism**: Frosted glass effects on cards
- **Animated Backgrounds**: Gradient animations and floating elements
- **3D Effects**: Tilt animations on service cards

### ⚡ Interactive Features
- **Typed.js**: Animated typing effect in hero section
- **Counter Animation**: Animated statistics counters
- **Smooth Scrolling**: Enhanced navigation experience
- **Form Validation**: Contact form with error handling
- **Portfolio Filtering**: Filter projects by category
- **Mobile Menu**: Responsive navigation menu

### 📱 Pages Overview

#### 1. **Home Page** (`index.html`)
- Hero section with typing animation
- Services overview with hover effects
- Why Choose Us section
- Client testimonials
- Animated statistics
- CTA sections

#### 2. **About Page** (`about.html`)
- Company mission & vision
- Our story timeline
- Core values display
- Team/founder section
- Company philosophy

#### 3. **Services Page** (`services.html`)
- Detailed service listings
- Pricing tables with 3 tiers
- Service benefits & features
- Custom solutions option
- Clear CTAs for each service

#### 4. **Portfolio Page** (`portfolio.html`)
- Project showcase grid
- Filter by category
- Case study results
- Client testimonials
- Results summary statistics

#### 5. **Contact Page** (`contact.html`)
- Contact form with validation
- Contact information cards
- FAQ section
- Multiple contact options
- Business hours

### 🛠️ Technologies Used

#### Frontend
- **HTML5**: Semantic markup
- **Tailwind CSS**: Utility-first CSS framework
- **JavaScript**: Vanilla JS for interactivity
- **Font Awesome**: Icon library

#### Libraries & Plugins
- **Typed.js**: Typing animation
- **Custom Animations**: CSS animations & transitions
